# System index

- [[schema]] — operating structure and preservation rules
- [[catalog]] — controlled vocabulary
- `templates/` — reusable record shapes
- `agents/` — descriptive roles and responsibility boundaries
- `skills/` — reusable executable agent workflows
- `automations/` — scheduling contracts and activation status

The repository-level `AGENTS.md` defines project policy, while `skills/` contains the executable workflows used by compatible agents.
