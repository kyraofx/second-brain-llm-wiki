# Obsidian
### What It Is
A local application for browsing and editing linked Markdown notes.
### What It Can Do
- Render wikilinks and backlinks.
- Navigate folders and linked records.
- Open `demo-vault/` without changing the Markdown source format.
### Experience Log
#### [[2026-02-01]] — Open the demo vault
- Goal: Inspect the synthetic Second Brain as a connected knowledge system.
- What I tried: Opened `demo-vault/` as a vault.
- Result: The Markdown structure remained directly readable in and outside the app.
- What I learned: The architecture does not require an application-specific database.
### Strengths
- Local, human-readable files
- Useful linked-note navigation
### Limitations
- Agent workflows run outside Obsidian in version 1.0.
### Current Verdict
- Useful as an interface; Git and Markdown remain the durable foundation.
